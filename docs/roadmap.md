# Learning roadmap

## Level 0–1: foundations
Read `01_python_ai_foundations`. A model is a function with parameters; training changes parameters, while inference uses them.

## Level 2: LLM foundations
Run tokens, embeddings, next-token prediction, and attention in order. These are small illustrations, not a modern LLM.

## Level 3: local AI
Read `docs/local-models.md`, then run `06_local_llm`. Ollama is an inference server; the model weights and tokenizer are separate ideas from the Python client.

## Level 4–6: systems
Structured output leads to allow-listed tools, an agent loop, memory, and retrieval augmented generation.

## Level 7–8: build and research
Use `examples/simple_agent` as the capstone. Measure it with `12_evaluation`, then investigate the linked papers and your own research questions.
