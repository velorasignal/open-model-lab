# Contributing

1. Keep examples runnable with Python 3.10+ and a normal laptop.
2. Prefer the standard library and explain every new dependency.
3. Label simplifications as educational simplifications.
4. Add a small test for deterministic behavior.
5. Never add unrestricted shell execution, secrets, or claims that a toy agent thinks like a person.

Run `python -m pytest` before opening a pull request. Improvements to explanations and experiments are first-class contributions.
