# 05 — Transformers and attention

Attention calculates how strongly a query relates to keys, then mixes their values. It is one conceptual ingredient of a Transformer, alongside feed-forward layers, normalization, residual connections, and positional information.

```bash
python 05_transformers/attention_demo.py
```

**Experiment:** change the query and observe which value dominates. This is an educational simplification, not a complete Transformer.
